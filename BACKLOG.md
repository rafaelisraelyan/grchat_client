- **Ed25519-подписи серверных конвертов (2026-10-13, v1.5.8-фича)** - полностью.
  - Схема: zero-substitution, байт-точная, без канонизации JSON. Сервер
    (`EnvelopeSigner.java`) вставляет `ts` + 128 нулей `sig`, сериализует,
    подписывает те же UTF-8 байты, заменяет нули реальным hex. Клиент
    (`lib/src/transport/server_sign.dart`) зануляет единственное wire-вхождение
    `"sig":"<128hex>"` и верифицирует на вшитом ключе.
  - fail-closed: sig есть, но неверна → строка целиком отбрасывается. sig нет →
    принимается (сервер без GRCHAT_SIGN_SEED, TLS остаётся границей).
  - Ключ: seed `C:\Users\GR\.grchat_dev\server_sign_seed.txt` (не печатать),
    pubkey `3fc81b698a57cc7c6113d3c47d4a0dddc911554fa85f45c0ff6b928b897cbbf5`
    вшит в `server_sign.dart`; ротация - `dart run tool/server_sign.dart keygen`
    + пересборка клиента (или --dart-define=GRCHAT_SERVER_PUBKEY).
  - Кросс-имплементационный пин: RFC 8032 §7.1 TEST 1 в Java и Dart тестах.
  - Живо проверено: строка реального сервера верифицируется вшитым ключом,
    тампер → bad. mvn 67/67, flutter 318/318.
  - Сервис рестарта стойки с подписью: `stack_keys_env.ps1` читает seed в env.
  - Обратная совместимость: старые клиенты незнакомые поля игнорируют; оба
    поля чисто аддитивные.
